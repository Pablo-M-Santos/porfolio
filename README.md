## 🚀 Sobre o projeto

Este é meu portfólio pessoal desenvolvido com **Next.js**, com foco em apresentar minha trajetória como desenvolvedor Full-Stack, meus projetos, experiências e stack tecnológica de forma moderna, performática e responsiva.

O projeto foi construído com foco em:

- Performance e otimização
- UI moderna e responsiva
- Arquitetura modular de componentes
- Experiência de usuário fluida (UX)
- Boas práticas de desenvolvimento
